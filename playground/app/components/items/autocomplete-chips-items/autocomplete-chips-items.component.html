What to look for
  • Every option and every selected chip carries a second line — that is subTemplate, a fn handed the value object the item's values fn produced. Multiple also sets template, which formats the first line the same way instead of rendering the value object's own name.
  • Single is multiple: false. It holds one value rather than a list, its query param is a bare value, and picking an option closes the popup instead of waiting for more. It renders without a chip outline: a lone value reads as a value, not as a chip.
  • Square and Shapeless are the shape option, passed straight through to fs-autocomplete-chips.
