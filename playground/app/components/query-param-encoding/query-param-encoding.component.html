  4. Refresh. The #1 is gone from the chip and status is gone from the filter.

What is going on

QueryParamController._replaceState rewrites the address bar on every filter change, and finishes with decodeURIComponent over the whole query string so the id:label separator reads as : rather than %3A.

It re-reads the address bar it wrote last time, so that decode runs again on each change and peels off another layer of encoding. %25 is the escape for a literal %, so a label holding a # decays %2523 → %23 → # in two passes. The same applies to & and =.

Fix: decode only the separator and never %25 — url.search.replace(/%3A/gi, ':') in place of decodeURIComponent(url.search). That makes the method idempotent, which is the property it is missing.
